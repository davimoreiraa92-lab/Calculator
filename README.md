
# 🧮 Calculadora Web

Uma calculadora simples desenvolvida com **HTML, CSS e JavaScript puro**, com foco em lógica de programação, manipulação do DOM e tratamento de entradas do usuário.

---

## 📌 Demonstração

Projeto de calculadora funcional com operações básicas:

* Soma
* Subtração
* Multiplicação
* Divisão
* Suporte a números decimais
* Tratamento de erros (ex: divisão por zero)

---

## 🚀 Funcionalidades

* Interface de calculadora interativa
* Inserção de números e operadores via botões
* Suporte a ponto decimal (`.`)
* Botão de limpar (`C`)
* Botão de deletar último caractere (⌫)
* Cálculo de expressões simples
* Prevenção de:

  * múltiplos pontos decimais
  * operadores inválidos consecutivos
  * divisão por zero

---

## 🧠 Conceitos praticados

Este projeto foi desenvolvido com foco em:

* Manipulação do DOM
* Event Delegation
* Estrutura de estado (variáveis `current`, `previous`, `operator`)
* Controle de fluxo com condicionais
* Lógica de operações matemáticas
* Tratamento de edge cases
* Organização de código frontend

---

## 🛠️ Tecnologias utilizadas

# 🧮 Web Calculator

A simple calculator built with **HTML, CSS, and Vanilla JavaScript**, focused on programming logic, DOM manipulation, and user input handling.

---

## 📌 Demo

A functional calculator project featuring basic operations:

* Addition
* Subtraction
* Multiplication
* Division
* Decimal number support
* Error handling (e.g., division by zero)

---

## 🚀 Features

* Interactive calculator interface
* Number and operator input via buttons
* Decimal point (`.`) support
* Clear button (`C`)
* Delete last character button (⌫)
* Simple expression calculation
* Prevention of:

  * multiple decimal points
  * consecutive invalid operators
  * division by zero

---

## 🧠 Concepts Practiced

This project was developed with a focus on:

* DOM manipulation
* Event Delegation
* State management structure (`current`, `previous`, `operator` variables)
* Conditional flow control
* Mathematical operation logic
* Edge case handling
* Frontend code organization

---

## 🛠️ Technologies Used

* HTML5
* CSS3
